# 阶段 4B 文件业务约定

本 PR 基于未合并的阶段 4A；不视为用户验收。仅虚构数据开发，生产启动保护不变。

## 接口与权限

所有接口经过全局 JWT 和 CaseAccessGuard，服务事务内再锁父案件并复核；不存在与无权限统一返回 403。沿用 OWNER-only，EDITOR/VIEWER 仍拒绝，阶段 9 再完整开放矩阵，不宣称协作上传已交付。容量从案件 owner 取得，不接受客户端指定 owner。

| 接口 | 行为 |
|---|---|
| POST /cases/:caseId/documents/presign | fileName、mimeType、sizeBytes、contentMd5；可选 previousDocumentId。返回 uploadId、签名、绑定请求头、到期时间、安全文件名和自动版本号 |
| POST /cases/:caseId/documents | 必填 uploadId、category；不接受对象键、大小、来源或任意版本覆盖。已完成同票据同分类可幂等重试 |
| GET /cases/:caseId/documents | category 可选；默认当前版本，includeHistory=true 包含保留历史；page/pageSize 有界分页 |
| GET /documents/:documentId/download | 复核归属、文件状态和对象存在性后签名；最长十分钟，响应禁止缓存 |
| PATCH /documents/:documentId/client-visibility | 仅 isClientVisible 布尔值；同事务审计，不因此开放客户门户 |
| DELETE /documents/:documentId | 软删除指定版本；当前版被删时提升最新未删除版本；不物理删除、不释放容量 |

业务返回不含内部 storageKey，容量为十进制字符串。文件名经安全化；允许 PDF/DOC/DOCX/JPEG/PNG/MP4，1–200 MiB；MIME 与扩展名匹配。MD5 仅作对象存储传输校验，不是安全扫描或身份认证。下载强制附件；后续解析不应信任内容类型声明。

## 票据、版本与容量

- DocumentUpload 是辅助运行记录，没有签名 URL；其对象身份、归属、摘要、长度、版本和到期时间由数据库触发器禁止修改。
- 临时键与正式键使用不同服务端 UUID，均满足 ownerId/caseId/documentId/version_fileName 结构。签名只能上传临时键，正式键不提供 PUT 签名。
- 新文件建立独立 versionGroupId；指定同案件未删除 previousDocumentId 才建立下一版。版本在申请时分配，包含已有文档和历史票据，过期或取消申请可造成跳号，但绝不复用版本。乱序完成时以最大的已登记且未删除版本为当前版。
- 申请时预留未完成且未过期票据的字节量；同所有者最多二十个有效未完成申请。登记仍重新校验实际对象和当前 quota，降级或并发不会超额。
- 锁序统一为案件→所有者→票据；跨案件争用同一所有者行锁。所有保留版本和软删除对象继续占容量。既有案件软删除也保留容量，物理销毁与容量释放政策尚未实现。
- 归集管道可使用内部服务入口指定 source/ingestionId，申请和登记都验证同用户、同案件、渠道及活跃匹配状态。公开手工接口拒绝来源覆盖。阶段 6 归集管道及真实渠道不在本 PR。

## 登记、故障与回收

登记在锁内读取真实对象大小、MIME 与单段上传 ETag，对照票据；以源 ETag 为条件复制到正式键，再核对目标。Document、当前版本切换、owner 已用容量、票据完成和 AuditLog 同事务提交。登记失败不会留下半套数据库状态。

复制成功但数据库失败时可能暂留对象，不能把它误报成“完全回滚对象存储”。票据始终保存两个键，可重试或清理；数据库提交结果不确定时，禁止在 catch 中立即删除正式对象。

每分钟处理最多十条过期至少一分钟的票据。回收再次锁案件/票据，只删临时对象和没有正式 Document 的孤立目标；软删除 Document 也保护其正式对象。完成状态与清理审计同事务。失败保留未清理状态，下轮重试；持续存储故障可造成积压，需要后续运维监控和更完整的回收调度。

已签发下载链接在到期前仍可使用，软删除、登出和可见性变化不能追溯撤销该链接；最长十分钟。清理不是恶意文件扫描、生产备份或合规销毁机制。

## 数据迁移与回退

追加第九条迁移 `20261015000000_document_uploads`，不重置既有数据、不修改前八条迁移。回退业务到 4A 时停止本版本服务，保留新增表、对象、容量及审计，禁止通过删表/清桶回退。已生成业务数据的恢复、配额回填、云备份演练须由专门迁移处理，未执行生产迁移。
