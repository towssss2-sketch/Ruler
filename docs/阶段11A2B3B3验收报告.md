# 阶段 11A2B3B3：本机隔离模式与开发入口关闭

日期：2026-10-18。[PR #15](https://github.com/towssss2-sketch/Ruler/pull/15)，基于未合并 PR #14，本轮只完成本机入口收紧和客户端回归，未开放公共测试环境；所有 PR 均待用户验收。

## 用户可见变化与边界

- 新增显式 `restricted-local` 模式，必须使用本机 HTTPS，且为开发/测试环境。空值、未知模式、公共监听地址、生产或缺失 TLS 拒绝启动，不回落为开放开发模式。证书材料继续受上轮有效期、主机、配对和 TLS 1.2 下限检查。
- 注册和验证码通过处理器元数据识别，先于鉴权限流及业务执行返回 404，不依赖 URL 字符串黑名单；Swagger 页面、规范及资源不注册。模式启动时固定，请求头/查询/正文和进程环境变量变化不能打开入口。
- 默认开发模式保持原注册产品能力与文档，不改变原 v3 的功能需求。已有账号的登录、案件、任务、文件版本、权限隔离和登出仍可用。
- 真实联调先用正常验证码注册流程准备两个随机虚构账号，关闭准备服务，重启隔离服务。账号没有公开发放，验证码只在准备进程内读取，不增加取码接口、固定口令或绕过注册服务的入口。
- 不新增依赖、不修改数据库模型、不购买、不部署、不开放公网。系统文件窗口、公共网关、账号安全发放与到期吊销仍待后续。

## 用户如何验收

在本 PR 成功 Actions 的 Artifacts 下载 `ruler-client-restricted-validation`，解压后打开 `client-restricted-acceptance.html`。应看到“10 项通过，0 失败，0 跳过”和“额外 12 项入口检查通过”，以及关闭准备服务后重启的说明。

无需修改配置、证书或代码，也不需运行命令。回复“通过”或“不通过＋报告现象”即可。安装包仍没有公共 API 地址，不能据此直接登录手机体验。

## 风险、清理与回退

本模式是本机入口控制，不是完整公共安全边界，也不是测试账号发放/到期机制。公共网关白名单、可信公共证书、限权存储身份、运行保障及真机验证未完成，D-05、D-06、D-10 保持待决。临时文件入口转发器不可用于部署。

联调只清理本次 schema、Redis 前缀、桶、证书及两个应用实例，不修改既有 .env 或字段密钥。模式切换需重启；若撤回本 PR，原开发注册/验证码/文档会重新开放，所以任何未来公共环境必须先关闭入口再回退。没有数据库回滚需求，不自动合并。
