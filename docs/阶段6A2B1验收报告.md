## 用户可见变化

连接版“材料待定区”现在可点击“导入设备文件”，无需先选择案件。选择 PDF、Word、JPEG/PNG 或 MP4（单文件不超过 200MiB），确认后上传；显示进度，支持主动停止。只有后端完成接收才提示成功。

- 上传失败保留原文件快照与票据；文件已传完但登记失败时显示“重试登记”，只重复原票据登记，不重复传输。过期票据需关闭后重新选择文件申请，不自动延长签名。
- 完成后独立刷新待定区；如果只是列表读取失败，点击“重新加载”仅重新读取，不再提交文件。关闭操作时接收可能已提交，页面也重新读取供核对；停止不代表撤销服务器已接收的材料。
- 附件条目显示名称和大小，“查看材料”显示附件资料与接收说明，不把文件名说明冒充提取正文。文字材料仍可“查看原文”。
- 点击“下载原件”使用系统保存流程，每次重新申请授权、核对下载字节数；取消保存和下载失败均有提示。忽略后附件仍保留在“归集历史”，可查看和下载。
- 会话失效销毁旧账号页面和文件工作；页面/账号释放连接，取消传输，晚到选择结果只清理临时副本，不恢复旧窗口。
- 离线“添加虚构文件示例”仅添加本次内存元数据，可以查看、去重、忽略和看历史；明确无真实原件，不读取设备文件，也没有虚假下载按钮。关闭应用清除。

分类与指派案件需要转正式文件事务，另拆 6A2B2，本轮未实现。既有案件文件的 11 类分类继续保留，含起诉材料、答辩材料、法院文件、开庭传票、服务合同。没有自动微信分享、聊天读取、AI、正文提取、任务建议或法定期间计算。

## 无需代码的验收方法

不安装：在本轮 Actions 下载 `ruler-client-experience`，解压打开 `client-acceptance.html`，查看新增三个截图及 190 项实际检查结果。用户无需阅读代码、修改配置或运行命令。

默认测试包可直接体验离线部分：

1. 安装 Android debug APK，或将 Windows 测试 ZIP 完整解压后运行 EXE。
2. 点击“开始虚构体验”→案件列表右上角“材料待定区”。
3. 点击“添加虚构文件示例”，应出现文件名、大小及“虚构示例，无真实原件”；不应出现真实下载按钮。
4. 点击“查看材料”，应看到附件资料及明确的未提取正文说明。
5. 再点“添加虚构文件示例”，应仍只有一条。
6. 点击“忽略材料”→“取消”，条目保留；再次点击并确认，待定条目移出。
7. 点击“归集历史”，附件和已忽略状态仍在；再次添加同一示例，不恢复待定、不新增第二条。

在线文件选择/上传/系统保存已接入，但需后续交付受控测试服务和账号才能在你的设备验证。当前用真实 Dart/后端/MinIO 联调核实网络行为，用 Widget 核实界面行为，不能据此宣称真机已通过。你只需回复“通过”或“不通过＋现象”，无需自行搭服务。

## 实现边界、风险与回退

后端列表/详情只新增可空附件摘要：id、fileName、mimeType、十进制 sizeBytes；继续绑定当前用户和未删除记录，不带对象键、内容指纹、签名或用户标识。没有新增数据库迁移。新客户端兼容文字无附件的旧响应，旧客户端忽略新增字段；附件界面须配套本轮后端。

共享设备保存端口改用名称、大小及授权下载回调，案件文件和待定附件复用同一保存实现，不伪造案件分类或版本。上传和下载仍使用独立存储连接，不发送登录令牌、不追随重定向；只使用构建允许的存储源。快照仅当前操作持有，结束/取消尽力清理；系统拒绝删除或强杀可能留下私有缓存，保存提供方拒绝清理可能留部分目标文件。

继承后端边界：忽略/软删保留原件和容量；已有下载签名最长十分钟仍可能有效；重传同内容返回首份名称与状态。没有撤销忽略或容量回收入口。未购买资源、开放公网、调用真实微信/法院/AI 或真实 OSS。

回退本轮客户端和附件摘要扩展不删除服务端文件。不要回退到不理解暂存配额的更早后端继续开放上传；保留 6A2A 表、票据、原件、配额和字段密钥。下一块 6A2B2 实现 11 类分类、案件选择与正式文件指派事务。所有前置 PR 仍待验收。
