## 用户可见变化与需求依据

原始 v3 第 3 节要求案件更新接口，第 11 节要求新建/编辑案件表单。后端已有更新接口，但客户端之前只能创建和删除，本轮增加“编辑案件信息”：回填案号、案由、法院、审理阶段、案件状态；支持一审/二审/执行/再审、进行中/已结案。保存成功更新详情与返回后的列表；重新打开编辑可继续修改。

案号中英文括号及空白统一，格式错误或空案由/法院阻止提交。保存中禁用输入、取消、重复提交和系统返回；服务失败保留输入，取消不写入；会话失效销毁在线表单与旧账号页面。

只向已有 PATCH 接口发送上述五项基础字段，不发送当事人、备注、费用、文件或任务字段，避免误清空。标记结案只修改案件状态，不自动完成任务、不删除文件，也不生成法定期间。在线页面显示阶段及状态；未知服务端枚举明确报错，不能默认显示为进行中。

无需登录的离线体验也增加相同编辑表单，保存到本次进程内存；会保留该体验案件的示例文件与任务，关闭应用后清除。离线编辑不等于云端保存。

本轮未包含当事人动态增删/联系方式、利益冲突检查界面、全部案件字段、筛选或协作权限 UI，不能称为完整案件管理客户端。

## 你如何体验

1. 下载本轮成功 Actions 的 `ruler-android-debug-apk` 或 `ruler-windows-test-zip`。Windows 解压两层后保留全部文件，双击 `ruler_client.exe`；Android 安装 `app-debug.apk`。
2. 打开“开始虚构体验”→“新建案件”→保留默认虚构信息创建。
3. 在“示例文件”添加一条，在“工作任务”添加一项；回到“案件信息”，点击“编辑案件信息”。
4. 修改案由，选择“二审”“已结案”，点击“保存体验修改”。详情应立即显示修改，示例版本和待办数不变。
5. 再次编辑改回“进行中”；试改文字后点“取消”，原记录不应变化。返回列表查看新案由，重新进入仍保留本次修改。
6. 不安装也可下载 `ruler-client-experience`，双击 `client-acceptance.html` 查看中文测试和实际截图；真实服务联调证据位于 API/HTTPS/隔离模式报告包。

只需回复“通过”或“不通过＋操作现象”。当前测试服务登录尚未开放，无需填写真实账号、修改设置或运行命令。

- 在线编辑沿用后端最后一次成功写入生效的语义，尚无多人同时编辑冲突合并；两端同时修改同一基础字段可能覆盖，需要后续独立设计。失败/超时后可刷新核对服务端，不能把未收到响应理解为肯定未保存。
- 无新增数据库迁移，可回退本 PR 恢复上一客户端；已保存的案号/阶段/状态仍在后端保留，不通过删除数据回退。上一版暂不显示状态，但不自动重写。
- 本轮补齐可直接点击的基础编辑；后续继续案件当事人/详情与分类文件使用流程，公网账号交付方案保持独立待审阅。D-05 法律期间、D-06 维护升级等未决项不被本轮关闭。
