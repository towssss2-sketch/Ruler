## 工程约定与风险

- 上传签名绑定 MIME、长度、Content-MD5；限制六类文件和 200 MiB，上下传签名最长 600 秒。下载强制附件、禁止共享缓存。
- MD5 是存储协议的传输校验，不是抗碰撞证明、文件安全检查或用户认证。阶段 4B 仍须核验实际对象和资源归属。
- 对象键严格采用 ownerId/caseId/documentId/version_fileName；路径穿越、控制字符、未规范化键被拒绝，中文文件名按路径段编码。
- 签名是到期前有效的访问凭据，不能承诺即时失效或一次性使用。正式文件不能继续暴露在旧上传签名可覆盖的位置；阶段 4B 应隔离待登记对象，核验后复制并设计失败补偿。
- 对象不存在与桶/权限/网络故障区别处理，后者不能伪装成“没有文件”。SDK 异常统一固定消息，不附原始异常或签名地址。
- 原需求指定的 SDK 固定版本：@aws-sdk/client-s3 / s3-request-presigner 3.1151.0，ali-oss 6.23.0；仅开发类型声明 @types/ali-oss 6.23.3。S3 SDK 从开发依赖移到运行依赖，没有更换技术栈。
- 存储配置经 zod 验证：开发 MinIO 只允许本机端点；OSS 限定匹配区域的官方 HTTPS；不生成或要求真实 OSS 密钥。OSS 临时凭据刷新、RAM 最小权限、桶策略、CORS、真实云联调仍待专门验证。全局生产启动保护保持。
- 本阶段新增 `init-storage-dev.mjs`，只向忽略的 .env 补充非敏感开发参数，不覆盖已有配置，不创建实际云桶。
