## 用户如何体验与验收

当前直接阅读上述中文方案，或者在本 PR 成功的 Actions 下载 `ruler-preview-plan`，解压后打开 `preview-plan.html`。核对资源、地域、费用上限、试用期限是否合适，回复“方案通过”或具体调整项即可，无需读代码、运行终端或重装客户端。
