# 阶段 11A1：客户端虚构交互体验

日期：2026-10-16（北京时间）。状态：READY_FOR_USER（待验收），本地检查与功能 CI 四项全部通过。[PR #8](https://github.com/towssss2-sketch/Ruler/pull/8) 基于未合并的阶段 5A；此前阶段仍未验收，不自动合并、不生产部署。

## 为什么提前交付

用户希望能实际操作客户端。按开发蓝图“先贯穿式最小闭环”的策略，提前拆出阶段 11A1；没有删去第 11 阶段的真实接口、离线缓存、平台上传与完整页面要求。

目前测试后端仅监听本机，开发验证码仅进程内投递，尚无可供手机安全访问的测试 API 或用户可用的注册交付。不能把伪造登录、验证码取码接口或内存演示说成真实接入。本 PR 先交付明确标注的离线交互版，真实闭环接入留 11A2。

## 实际可操作的内容

- 欢迎页点击“开始虚构体验”，进入有空状态、刷新和搜索的案件列表。
- 以默认虚构案号、案由、法院创建案件，查看详情及示例版本/待办计数。
- “示例文件”添加虚构材料条目、观察递增版本、查看说明、移除条目；不是设备文件选择或 PDF 生成。
- “工作任务”添加普通体验任务、标记完成、恢复待办；不计算法定期间、不发送提醒。
- 返回列表搜索，确认后移除体验案件。浅色/深色与窄屏布局可操作。

所有数据仅在本次应用进程内存中，返回欢迎页不会自动清除，但关闭应用后清除。持续提示“离线虚构体验”，不连接真实账号/云端，不写磁盘或调用网络。没有注册/登录、真实文件上传下载、后端持久化或 drift 缓存，不能用此版本存放真实材料。

## 你如何体验

1. 打开 [本次成功的 RULER 检查与测试包](https://github.com/towssss2-sketch/Ruler/actions/runs/38860973288)。
2. Android 下载 `ruler-android-debug-apk`，解压后安装 `app-debug.apk`。若旧测试包提示签名不同，可卸载旧测试包后安装。
3. Windows 下载 `ruler-windows-test-zip`，解压外层与内层 ZIP，保留 DLL/data，双击 `ruler_client.exe`。
4. 点击“开始虚构体验”→“新建案件”→保留默认虚构信息→“创建体验案件”。
5. 在“示例文件”添加两次版本；在“工作任务”添加任务、完成并恢复。
6. 返回列表搜索，进入“案件信息”移除体验案件。可切换系统深色模式再看布局。
7. 下载 `ruler-client-experience`，解压后打开 `client-acceptance.html`，查看中文测试结果与实际渲染截图。

你不需要读取代码、配置服务器或运行命令。有空再反馈“通过”或“不通过＋点击步骤/现象”；继续开发不表示验收。
