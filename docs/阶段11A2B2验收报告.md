更新：2026-10-17。基于未合并 PR #10。本次新增设备文件操作代码和界面；本地 Flutter 71 项、真实联调 9 场景通过。Android 本地构建/签名已通过；最终云端结果以本 PR 最新 Checks 为准。没有可达测试服务或交付账号，默认安装包仍不能直接登录，不能称为已通过真机验收。

## 用户可见变化

- 案件文件页增加“上传文件”“上传新版本”“下载保存”。选择后展示文件名与大小，选择归档分类，显示传输进度，登记完成后刷新列表。
- 登记失败保留同一文件快照与票据，“重试登记”不再上传一次；关闭窗口取消本次传输。已经发出的登记可能在服务端完成，关闭后刷新核对，不承诺撤销已成功写入。
- 新版本绑定原文件，默认沿用分类。系统选择取消不发上传请求；晚到的选择结果在旧页面销毁后仅清理，不恢复旧页面。
- 下载完整校验后，Windows 打开系统保存窗口；Android 使用系统创建文档窗口。取消保存不显示成功，保存失败显示固定中文提示。

## 工程与边界

- D-09：用户在两个组件的具体确认问题后回复“继续”，按同意该方案实施并已向用户说明。直接依赖仅增加官方 file_selector 1.1.0、crypto 3.0.7，固定版本及传递依赖；不扩大为其他依赖、生产或合并授权。
- 上传先在私有暂存目录复制快照，分块计算 MD5，精确核对 1 字节至 200 MiB 的长度。摘要和上传读取同一个快照，原文件不修改。MD5 是传输校验，不是安全扫描。
- Android 的官方选择器先复制到应用缓存，适配器再校验大小并生成自己的快照；可能短时占用两份文件空间。超过上限时拒绝上传，但不能保证系统提供方在返回前不占用缓存空间。正常结束清理本次缓存副本，不删除用户原文件、不申请全盘读取权限。
- Android file_selector 没有另存为接口，因此使用原生 ACTION_CREATE_DOCUMENT 桥接；仅接受指定私有暂存目录的源文件，后台线程复制，取消/销毁停止继续写入。失败尝试删除本次新建文档；文档提供方可能拒绝清理，界面提示检查目标位置的不完整文件。
- Windows 先在目标目录完整写入中间文件，再替换用户在保存窗口确认的目标；取消或复制失败不先清空旧文件。已有文件覆盖由系统窗口确认。
- 临时副本在正常结束、失败、关闭路径清理。进程被强制终止或系统拒绝删除时可能留在私有缓存，尚无跨启动清理调度；不得输入真实资料。200 MiB 真机内存/空间、系统文档提供方、后台生命周期仍待验证。
- 本轮为前台传输；Windows 拖拽、Android WorkManager 后台续传、离线缓存仍未实现，没有删减原需求，留后续小 PR。
