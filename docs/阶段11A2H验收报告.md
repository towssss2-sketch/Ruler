## 交付与需求对应

原始 v3 第 1 节 Case 包含 judge、clerk、clerkPhone、fee、feeStatus、备注，第 3 节要求 PATCH 更新。后端已经支持，本轮补齐客户端编辑入口，无后端规则、依赖、迁移或账号策略变化。

- 从“案件详情与当事人 → 编辑其他案件信息”修改审判员、书记员、电话、费用金额、费用状态和备注；在线由授权详情预填，离线由当前内存快照预填。
- 文本去除首尾空白，保留备注内部换行。审判员/书记员最多 128 字、电话 64 字、备注 10000 字；五项可选值留空保存会明确清空为 null。
- 金额是非负十进制字符串，最多十二位整数、两位小数，全程不转浮点数。`0` 保存为 `0.00`，留空表示未填写；负数、逗号、科学计数法和超精度均拒绝。支持未付、部分已付、已付、免收，状态只作记录，不执行收付款，也不根据金额自动修改。
- 六字段一起 PATCH，不携带基础字段或名单；基础信息、当事人、文件、任务保留。离线修改同时更新案件排序时间，其他页面操作也保留这些新资料。
- 取消不写；保存期间禁用输入、选择、按钮和系统返回。失败保留草稿可重试；成功才退出并独立 GET，GET 失败只重新读取。会话失效销毁旧账号详情和输入。
- 详情现在在线/离线都显示这些资料。没有新增磁盘缓存、AI 分析或公共服务。

## 点击验收，无需代码或命令

1. 下载本轮 Android APK 或 Windows 测试 ZIP，解压安装/运行；Windows 保留同目录全部配套文件。
2. 进入“开始虚构体验”，创建虚构案件，再打开“案件详情与当事人 → 编辑其他案件信息”。
3. 填写“虚构审判员甲”“虚构书记员乙”“虚构电话”；费用填 `123.4`，状态选“部分已付”，备注填写两行虚构文字，点“保存体验资料”。
4. 详情应显示 `123.40 · 部分已付`、姓名、电话和两行备注。返回上一页再进入，仍保留本次体验值。
5. 再编辑费用为 `1.001` 并保存，应提示金额格式错误且保留输入。改成 `0` 保存，应显示 `0.00`。
6. 清空电话、金额和备注并保存，应显示未填写；当事人和原任务/示例文件保持。修改后点“取消编辑”，原保存值不变。
7. 不安装也可下载 `ruler-client-experience`，解压打开 `client-acceptance.html` 查看中文结果和实际渲染截图。

只需反馈“通过”或“不通过＋现象”。公共地址和账号尚未交付，设备无需尝试连接本机测试端口。

## 风险与回退

- 所有输入仅限虚构资料；在线继续使用既有 OWNER 实时授权、书记员电话/备注加密和审计，不外传 AI、不持久化到客户端磁盘。
- 六字段整体保存，后一次成功更新生效；多窗口同时编辑可能覆盖这六项，不具备版本冲突合并。未知写入结果应刷新核对；已知保存成功后的重读失败不重复写。
- 费用是案件金额记录，没有收款、付款、会员计费或法定期间功能。D-05/D-06/D-08/D-10 均维持原状态。
- 离线仅当前进程保存，关闭后清除；真实联调不等于真机已连接公共数据库。
- 无迁移，可回退客户端业务提交，保留数据库、文件及原字段密钥。没有自动合并或生产部署。
