## 用户可见交付

真实后端提供邮箱验证码注册、密码登录、当前用户、两小时 Access JWT、三十天刷新会话轮换与登出；全局守卫默认拒绝匿名请求。新增开发 Swagger、脱敏请求 trace 日志、严格限流和案件/文档/任务 OWNER 资源权限验证。客户端仍是欢迎页，没有登录按钮。

| 中文场景 | 实际本地结果 |
|---|---|
| 验证码注册→登录→携带 token 查询自己 | PASS，只返回最小用户信息 |
| 访问别人案件、文件和任务 | PASS，403，无数据回显 |
| 伪造所有者参数、匿名访问、未知资源 ID | PASS，拒绝访问 |
| 软删除/主办转交后继续访问旧资源 | PASS，即时失效，无权限缓存 |
| 错误密码、错误算法/签名/受众/类型、过期 JWT | PASS，401 |
| 刷新轮换、旧凭据重放、并发重复刷新 | PASS，重放吊销会话 |
| 登出后使用 Access 或 Refresh | PASS，立即拒绝；另一个设备会话继续有效 |
| 过期/错误/重放验证码、重复注册 | PASS，拒绝；已核验的重复注册 409 |
| 更换邮箱或伪造转发 IP 绕过限流 | PASS，429；健康检查仍可用 |
| Redis 不可用、真实邮箱投递、公开取码 | PASS，故障拒绝、无真实投递/取码接口 |
