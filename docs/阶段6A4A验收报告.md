# 阶段 6A4A：正文提取记录与中断恢复

开发验证：2026-10-27；交付复核：2026-10-28（北京时间）。基于未合并 PR #31，本轮分支 `feat/ingestion-preview-recovery`；待验收，不购买资源、不公开服务、不合并、不生产部署。

## 用户可见变化

材料附件新增“提取记录”。可查看处理中、提取成功、需人工处理或处理已中断，以及北京时间的开始/结束时间、固定失败说明。查看、刷新、分页只读，不启动提取。首页最新记录若为中断/暂时故障，可明确点击“重新提取正文”，回到现有预览；仍须选择分类、案件并确认归档。全部 11 类保持。

在线记录在数据库保留，重登可读取；正文、分类候选、案号、文件名、对象键及签名不写入新表。离线记录只来自本次实际点击的固定虚构正文，返回页面保留、关闭应用清除。成功记录不意味着归档成功，再看正文会重新提取。

## 实现与范围

- 第 13 条迁移新增 IngestionPreviewAttempt 与状态枚举。组合外键绑定同用户附件；数据库约束状态/固定原因/时间组合，用户运行中唯一索引，身份/期限不可改，终态不可改写/删除。旧审计不回填为新记录，不伪造历史。
- begin 在既有用户行锁内创建尝试并审计；实际存储读取/解析在事务外。保留每实例最多两份解析，增加跨实例数据库每用户一份。两分钟租期用数据库时钟计算，不随客户端超时或重试延长。
- GET /ingestion/:id/preview-attempts 有界分页，倒序 startedAt/id，同一快照计数；未登录401，他人/删除/未知/无附件403，原始重复/未知/非法参数400。private,no-store；只返回 id/status/reason/startedAt/finishedAt/retryable。
- GET 对过期 RUNNING 只读呈现 INTERRUPTED，不写库；新 begin 或迟到 finish 原子固化中断与审计。新尝试有新 id，迟到/重复结束409，不覆盖新记录。旧失败完整保留。没有后台扫描器、队列或自动重试。
- 完成前再次核对授权；处理中删除时拒绝返回正文、记录固定 UNAVAILABLE（已过期则中断），释放本人其他材料的槽位。停用账号拒绝，遗留运行记录按租期处理。提交故障不把正文当作成功返回，开始记录保留供查询/恢复。
- 客户端严格解析分页/唯一身份/固定状态原因/UTC 时间与可重试组合；错误不当空清单。刷新和会话失效清除旧内容，晚到结果不复活窗口；历史弹窗可滚动，离线记录随 Provider 生命周期。

本轮是按需 Extract 的尝试状态基础，不是完整 IngestionPipeline。原 IngestionRecord.stage/归档版本/配额/原件及原 rawContent 密文不改变；分类/匹配阶段结果持久化、自动调度、OCR、姓名匹配与 AI 继续待实现。

## 中文体验方法

1. 安装本轮 APK 或解压完整 Windows 包，选择“开始虚构体验”。
2. 进入“材料待定区”，添加虚构文件示例，点击“提取记录”：应显示“尚无提取记录”。
3. 关闭记录，点击“查看正文示例”，再关闭。再次查看“提取记录”：应有一条“提取成功”。
4. 刷新记录不增加条数；再次查看正文示例会产生新记录。返回案件列表再进入待定区，记录仍在；完全关闭应用后离线记录清除。
5. 中断/失败场景的中文界面见报告截图。真实联网发生暂时失败后，记录保留；最新记录可重试时由你明确点击，不能自动归档。

小屏大字可上下滚动。`ruler-client-experience` 中打开 `client-acceptance.html`，查看 `client-preview-attempts.png`（故障协议替身）和 `client-preview-attempts-demo.png`（实际离线320×640、深色、1.4倍文字）。均为真实 Widget 渲染，非真机截图。后端报告 `ruler-ingestion-text-validation/ingestion-text-acceptance.html` 包含37项提取专项实际结果。

默认包尚无公共测试地址/账号，不能把离线记录当作服务端持久化体验。本轮不会要求所有者改配置、运行命令或读代码。

## 风险、回退与下一步

- 两分钟是“本次结果仍可提交”的租期，不是保证硬杀整个服务进程的时间；原解析/读取边界仍适用。GET 超时呈现不会修改数据库，后续开始/完成才固化终态。
- 状态元数据持续保留、分页有界，没有自动删除/归档策略。新表不包含正文；既有依赖维护 D-06 等待决议保持。D-05/D-08/D-10 不变。
- 回退前停止提取写入并等待在途请求结束；保留新表、状态记录、原件、配额和字段密钥。旧实例不理解数据库槽位，不能与新实例混跑；优先前向修复，不能删库回退。
