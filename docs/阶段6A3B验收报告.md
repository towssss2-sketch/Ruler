日期：2026-10-27（北京时间）。状态：本地验证通过，最终 CI 与测试包见 [PR #30](https://github.com/towssss2-sketch/Ruler/pull/30)，待用户验收。分支 `feat/client-ingestion-preview`，基于未合并 [PR #29](https://github.com/towssss2-sketch/Ruler/pull/29)。[本轮 Actions](https://github.com/towssss2-sketch/Ruler/actions?query=branch%3Afeat%2Fclient-ingestion-preview)。没有自动合并或生产部署。

## 已交付内容

在线材料卡片新增“提取正文”，接通既有 PDF/DOCX 后端：查看纯文本正文、标题分类建议和候选案号。用户点击“按建议选择分类”只预填类别，客户端重新读取材料，核对仍为待定且是同一附件，再打开原归档表单。仍须选择案件，可改选全部 11 类（含法院文件、服务合同），最终确认才归档；取消不写入。历史材料可预览但不能在预览中再次归档。

未知或冲突标题不给默认分类；候选案号不自动匹配案件。全部八种人工处理原因都有中文说明，仅超时和暂时不可用提供再次提取；接口故障也可主动重试。坏响应明确报错，不把部分正文或未知协议显示为成功。原件和已有归档保留，用户仍可下载并手动处理。

正文仅在弹窗内存中显示，关闭或会话结束移除，重新提取先清除旧内容；晚到响应不重新打开窗口。文本不执行 HTML、不自动访问链接或写入剪贴板，允许用户主动选择复制。关闭在途预览不承诺终止服务端处理，界面已有提示。每次新提取产生独立尝试，不是自动后台重试队列。

离线增加明确标注的固定“虚构正文示例”，复用真实界面和人工归档流程，不读取设备、不冒充真实解析。入口由实际应用 Provider 接通，窄屏深色流程测试包含最终归档。

## 用户如何体验

1. 从本轮 PR 下载新版 Android 测试 APK 或 Windows 完整 ZIP（解压整个文件夹后打开程序）。无需修改配置或读代码。
2. 点击“开始虚构体验”，先新建一个虚构案件。
3. 回到案件列表，打开“材料待定区”→“添加虚构文件示例”→“查看正文示例”。应看到明确的示例标识、正文、建议“服务合同”和候选案号。
4. 点击“按建议选择分类”→“选择案件”。类别可保持“服务合同”或改为“法院文件”等，再点“确认归档”。取消时不应产生文件。
5. 材料移至历史；可查看归档去向、进入该案件“示例文件”确认分类，也可使用已有撤回和重新分类功能。关闭应用后离线示例不保存。
6. 可以直接下载 `ruler-client-experience`，解压打开 `client-acceptance.html` 看真实测试截图；回复“通过”或“不通过＋现象”即可。

三张新增图片：`client-ingestion-preview.png`、`client-ingestion-preview-manual.png` 为协议替身 Widget 渲染；`client-ingestion-preview-demo.png` 为实际应用离线 320×640 深色渲染，均已本地检查。它们不是手机/Windows 真机截图。

当前默认安装包没有服务地址/账号，因此真实设备文件在线提取尚不能由用户直接体验。真实 PDF/DOCX 链路由上述自动联调验证；D-10 仍只授权准备方案，未购买或开放公网。
