## 为什么现在还不能直接登录上传

| 事项 | 当前真实状态 | 开放前工程工作 |
|---|---|---|
| API 与文件地址 | 安装包的 API 和文件白名单默认为空 | 获得真实域名、HTTPS 后，工程师为 APK / Windows ZIP 固化正确地址并重建，所有者不需改配置 |
| 文件链接 | 当前 MinIO 配置仅允许本机；真实驱动离线签名也指向本机 | 区分内部对象操作与设备可达的签名源，签名中的主机/端口不能事后简单替换；增加真实 HTTPS 上传、下载、历史版本、重试测试 |
| HTTPS 和边界 | 当前开发服务没有提供公共 TLS 入口 | 设计并实现隔离测试模式、证书更新及入口控制，保持生产启动禁用；不得把当前开发端口直接公开 |
| 虚构账号 | 自动化测试的账号会随隔离数据清理，尚未交付用户 | 通过本机管理流程调用正常注册服务，创建随机虚构账号；受限安全渠道一次性交付，提供重置、吊销与到期关闭流程，不开放取码接口或固定口令 |
| 注册、验证码及接口说明 | 开发接口尚未为公共测试关闭 | 公共入口仅允许测试所需路由；关闭公开注册/发验证码和开发文档，增加绕过路径与拒绝访问测试 |
| 数据服务及对象权限 | 本机开发配置已隔离，但不等于公网配置完成 | 数据库、Redis、MinIO 管理后台只在私网/本机；应用使用仅限测试桶的服务身份，不能把 MinIO 管理员凭据放入安装包 |
| 安全维护 | 既有后端依赖审计记录为 45 项（33 高、11 中、1 低），D-06 待决 | 开放前重新扫描、评估实际可利用路径并修复或明确可验证的隔离措施；本提案不关闭 D-06，不自行升级技术栈 |
| 真机 | Android / Windows 构建已通过；系统文件窗口及远程设备体验未验收 | Android、Windows 均执行下列流程，特别记录网络切换、取消与文件提供方行为 |

## 开通顺序与责任

1. **现在：审阅方案。** 可以回复“方案通过”或提出地域、预算、试用范围的调整。方案通过只确认方向，不触发消费、合并或部署。
2. **购买前：提供具体报价。** 工程师整理可下单规格、全部费用、域名候选和权限清单；需要你对账户/付款作明确决定。这些属于必须由所有者决定的事项，不要求你运行命令或读代码。
3. **实现并审查部署条件。** 拆小 PR 完成上表缺项。拟采用一个 API HTTPS 入口和一个文件 HTTPS 入口；本轮未选定或安装新网关，后续若需新增清单外依赖，先说明具体理由。端口、证书终止位置和内部对象访问路径必须在实施 PR 中明确并验证。
4. **测试部署前：审阅具体部署清单。** 明确域名、公开端口、私有数据服务、最小权限、预算、账号交付方式和关闭时间，经过测试且得到明确授权后才开放。不能把本轮方案检查绿灯当成授权。
5. **交付体验。** 工程师部署后在远程网络验证服务，再构建与该环境对应的 APK / Windows ZIP，提供临时账号和下载入口，标明版本与有效期。账号不放入 PR、Actions 日志、报告或聊天中的明文配置。

既有生产目标仍为阿里云 ECS/ACK、RDS、OSS、Redis、SLB；此处临时开发服务方案不替换生产架构，也不宣称生产可用。

## 届时你只需这样测试（当前尚未开放）

1. 安装交付的 APK 或解压完整 Windows 包，点击“测试服务登录”，使用安全交付的虚构账号。
2. 新建一个虚构案件，进入“案件文件”，选择交付的测试 PDF，分类后上传；确认列表中出现文件。
3. 新增一项普通工作任务，退出再登录，案件、任务和文件仍存在。
4. 给同一文件上传新版本，切换历史，下载保存到设备，再打开核对；取消选择或保存不应误报成功。
5. 分别在手机和 Windows 重复；切换第二账号后不应看到第一账号的案件。工程师另用自动化验证直接访问他人资源被拒绝。
6. 回复“通过”或“不通过＋操作及现象”。遇到失败无需改设置或自行排查服务器。

系统窗口、200 MiB 文件的内存与磁盘占用、弱网和应用退出行为仍需设备验证。暂不包含短信归集、AI、协作、计费、离线缓存、后台续传或未经律师确认的法律期限。

## 关闭、回退与清理

- 部署失败先关闭公共入口、吊销本次测试会话；保留隔离测试数据供定位。不得删除本地开发数据，不覆盖既有字段加密密钥。
- 回退应用到上一个已验证测试版本；数据库迁移须先核对兼容性和恢复演练，不能靠直接删除数据库“回退”。本提案 PR 本身无数据库迁移。
- 约定测试期结束时关闭入口并吊销会话，提醒所有者复核；保留期结束前核对虚构数据、备份和资源释放清单，经明确授权后清理。另核对云资源、IP、磁盘、快照及域名续费状态，不能把关机当作停止全部收费。
- 只清理本次隔离环境；记录清理结果和最终费用。未完成清理不得称“已无费用”，所有测试安装包标注环境已关闭。
