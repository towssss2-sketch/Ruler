日期：2026-10-22（北京时间）。基于未合并 PR #22，分支 `feat/client-today-dashboard`；待用户验收。[本轮 Actions 与测试包](https://github.com/towssss2-sketch/Ruler/actions?query=branch%3Afeat%2Fclient-today-dashboard)为最终云端证据，PR 说明补充对应运行与下载链接。

## 用户可见变化

对应原始 v3 第 5 节今日汇总与第 11 节今日优先级列表/迷你日历。在线、离线案件列表右上角新增“今日任务”日历图标；本轮不是完整 AI 助手首页。

- 跨案件查看未完成任务，不受案件列表搜索/筛选条件限制。在线保留后端排序：已有确认信息且进入预警窗口的法定期间优先，其次普通逾期、今日到期；未来普通任务、无日期、已完成、软删除和他人任务不混入。
- 在线卡片显示案号、法院、来源、日期及逾期/剩余天数，展开可读完整描述；点击“打开所属案件”实时读取授权详情后打开工作页，返回重新读取汇总。离线卡片显示体验案号。
- “标记完成”只写 status=DONE，成功后回第一页重读，防止最后一页完成后困在空页；失败保留当前列表并提示。写成功后读取失败只重试 GET，不重复 PATCH。保存中禁用页面操作及系统返回，会话失效销毁旧页面。
- 法定期间采用独立只读资料模型，显示期间类型和基准日，标记完成前额外确认；没有普通编辑/删除入口，不新增期间计算、登记确认或提醒。
- 日期来源在线为服务端 Asia/Shanghai，离线按设备时钟换算北京时间；日历只展示汇总月份并标记汇总日期，不展示未经全量查询的日程计数、不提供选日查询。返回应用、手动刷新回第一页；连续前台跨午夜需点击刷新，日期以页面明确显示的汇总日期为准。
- 分页栏固定在底部；离线从本次全部内存案件筛选并按日期/id 稳定排序，支持跨页和幂等完成，关闭应用后数据清除。离线同日顺序不冒充后端创建时间顺序。

## 接口与兼容

复用 GET /tasks/today、PATCH /tasks/:id 与 GET /cases/:id。今日响应仅新增 caseNo/court 两项摘要，通过同一授权查询选择读取；不返回嵌套案件、当事人或书记员联系方式。查询范围、事务隔离、候选上限 5000、排序、加密和权限规则保持不变，无新依赖或数据库迁移。

新客户端需要本轮后端提供摘要字段；旧客户端可以忽略新增字段。客户端拒绝未知来源、非法日期/时区/分页、重复任务、未确认期间及损坏资料，不能将错误显示为空清单。只显示服务端已有确认记录，不在客户端确认法律结论；D-05 保持待决。

## 无需读代码的验收方法

1. 下载本轮 Android 或 Windows 测试包，解压后安装/运行；Windows 保留同目录配套文件。
2. “开始虚构体验”→新建案件→“工作任务”→添加任务→“编辑任务”。填虚构描述，工作日期填当天北京时间日期，保存。
3. 返回案件列表，点击右上角日历图标“今日任务”；应看到任务、案号及“今日到期”。展开“查看日历”可查看当月日期。
4. 点击“打开所属案件”，应进入刚才的案件；返回应仍是今日汇总页。点击“标记完成”，该任务应移出清单；回案件任务页仍可看到已完成状态。
5. 将另一任务日期设为昨天，应显示“逾期 1 天”；设为明天或清空日期，应不出现在今日清单。可再建第二个虚构案件验证一起汇总。
6. 不安装可下载 ruler-client-experience，解压打开 client-acceptance.html 查看中文结果和实际截图。截图中的已确认期间为测试夹具，安装包不提供期间创建/确认。

用户只需回复“通过”或“不通过＋现象”。默认安装包没有公共服务和测试账号，无需尝试本机端口或修改配置。
