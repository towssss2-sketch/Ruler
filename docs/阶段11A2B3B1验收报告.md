# 阶段 11A2B3B1：存储内部地址与文件签名入口分离

日期：2026-10-18。[草稿 PR #13](https://github.com/towssss2-sketch/Ruler/pull/13) 基于未合并 PR #12。本轮完成本机可独立验证的工程改造，仍未购买服务器、部署公网或交付测试账号。最终云端证据见 [PR 最新 Checks](https://github.com/towssss2-sketch/Ruler/pull/13/checks)。

## 用户可见结果

为后续手机文件传输补上地址拆分能力：后端访问存储的内部地址与设备拿到的上传、下载地址可分开配置。默认行为兼容旧版本。本轮两个地址都只允许本机，安装包仍无可达服务，暂不需要重装。

工程改动：新增可选 `MINIO_SIGNING_ENDPOINT`，不设置时沿用 `MINIO_ENDPOINT`；显式空值、非本机、含路径/凭据/查询/片段的入口会被拒绝。PUT/GET 在独立入口直接签名，元数据读取、复制、删除继续走内部连接。相同地址复用一个客户端，不同地址分别释放连接；签名有效期与权限不变。

独立入口测试明确验证：

1. 本机随机端口保留 Host、路径、查询和签名头，真实 PUT 上传及 GET 下载内容一致。该入口只接收 PUT/GET，元数据、复制、删除仍能完成且未经过该入口。
2. 入口错误改写 Host 后，真实 MinIO 拒绝 GET/PUT，失败上传未生成对象。
3. 将已签名链接直接换成内部端口，真实 MinIO 同样拒绝，不能靠事后替换链接部署。

测试转发器只位于测试目录、只监听 127.0.0.1，固定本机上游，结束时关闭；仅操作本次随机测试桶及对象。它不是生产代理、网关或公共 TLS 实现。测试不输出签名链接、对象正文或密钥；协议虚构 PDF 字节用于存储校验，实际客户端联调使用仓库内有效虚构 PDF。

## 用户如何验收

在本 PR 成功的 Actions 下载 `ruler-storage-validation`，解压后打开 `storage-acceptance.html`，查找“真实 MinIO 独立本机文件入口”三项场景；均应显示通过。`ruler-preview-plan` 的中文报告会继续显示公网体验受阻，同时说明独立本机签名地址已完成分离。

不需要阅读代码、配置地址或运行终端。可回复“通过”或“不通过＋报告中的现象”。本轮没有新增可直接登录的手机服务，不把报告绿灯当作设备体验完成。
