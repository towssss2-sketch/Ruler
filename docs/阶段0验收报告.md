## 用户验收步骤

安装包生成后，进入 Actions → “阶段 0 检查与测试包” → 本 PR 成功运行 → Artifacts。
下载 ruler-android-debug-apk 或 ruler-windows-test-zip（具体入口会由 PR 链接给出）。
Android 安装 app-debug.apk；Windows 完整解压内层 ZIP 后运行 ruler_client.exe。

1. 打开后看到“欢迎使用 RULER”“阶段 0 · 工程与 CI 基座”和勿录入真实资料的提示。
2. 点击“查看本次交付范围”，确认能进入说明页并返回。
3. 切换系统浅色/深色主题，文字能阅读；窄屏可滚动。
4. Windows 窗口能缩放，最小客户区为 1024×720（受屏幕 DPI 缩放）。
5. 关闭再打开仍能进入欢迎页。当前无业务数据保存功能，也不应显示假登录成功。

通过后回复“通过”；不通过时描述设备、点击步骤、预期和实际表现即可。
