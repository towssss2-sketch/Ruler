## 用户可见变化与本轮边界

归集模块原先只有数据库结构，本轮先打通原始 v3 第 6/11 节的微信文字手动转发和待定区。案件列表右上角增加收件箱图标“材料待定区”，不需要先建案件。

- 点击“粘贴转发文字”，手动填写/粘贴虚构微信文字，保存进入待定区；不主动读取剪贴板、聊天、短信或邮箱。最多 10000 字，拒绝空白和零字节；不悄悄截短超长输入。
- 卡片展示来源、状态、北京时间接收时间和原文前 200 个码点；“查看原文”独立读取完整文字，不把链接变成自动访问入口。没有生成 AI 摘要或置信度。
- 同一用户、同一渠道、相同规范化文字只保存一次；规范化仅首尾空白及换行，内部空格/大小写保留。重复请求返回原状态和接收时间；已忽略材料不会自动恢复。
- “忽略材料”先确认，从待定区移出但在“归集历史”保留原文；当前版本不提供撤销忽略，确认框明确提示。重复忽略不重复修改/审计，已匹配或指派材料拒绝忽略。
- 待定与历史各自采用服务端分页，切换或成功写入后回第一页重读。写失败保留输入/列表；写成功后读失败仅重读。详情可独立重试，保存等待防连点/系统返回，会话失效销毁页面和原文对话框。
- 离线提供相同点击流程，Provider 仅本次内存，返回案件后再进入仍可查看，关闭应用后清除。在线使用真实数据库；默认包仍未配置公网地址或测试账号。

本轮只接收文字。文件暂存/附件上传、11 类分类与指派案件转正式 Document、自动提取/识别/匹配、任务建议、五阶段后台重试队列、短信/邮箱/系统分享接入均未实现，不计作通过。既有案件文件上传的 11 类分类（含法院文件、服务合同）继续保留；不是用文字记录替代文件归档。

## 后端与数据边界

新增 POST /ingestion/wechat、GET /ingestion/pending、GET /ingestion/logs、GET /ingestion/:id、POST /ingestion/:id/ignore。全局 JWT 实时校验，所有记录查询限定当前用户和未删除状态；外部不能指定 userId/channel/status/归属/对象键/AI 结果。归集是用户级资源，不扩大案件协作范围。

沿用既有 AES-256-GCM 与记录 AAD，正文中的链接也仅存在于密文；按用户/渠道域隔离的 HMAC-SHA-256 判重。列表仅摘要、详情原文，不返回哈希、密文、用户标识、对象键或独立链接字段。事务中锁用户与对应记录、同事务审计；创建和状态改变失败整体回滚，响应丢失通过同文判重安全重试。忽略不物理删除，不释放任何既有文件配额。

无新依赖、迁移、平台权限或云资源。记录保持 RECEIVE，后台管道尚未调度。字段密钥必须保留，未来轮换需迁移密文与内容索引；D-05/D-06/D-08/D-10 保持待决。

## 只需点击的验收方法

1. 下载本轮 Android 或 Windows 测试包，解压安装/运行；Windows 保留同目录全部配套文件。点击“开始虚构体验”。
2. 案件列表右上角点击收件箱图标“材料待定区”→“粘贴转发文字”。输入“虚构转发：请核对服务合同的归属。”→“保存到待定区”。
3. 应看到一张待定卡片；点“查看原文”应看到完整输入，关闭返回。
4. 再粘贴相同文字，应提示未重复创建，列表仍是一条。
5. 点击“忽略材料”→“取消”，卡片应保留；再次点击并“确认忽略”，待定列表应为空。
6. 点击“归集历史”，应看到“已忽略”记录，仍能查看原文；再提交同文，不应恢复待定或产生第二条。
7. 返回案件列表再进入，数据仍在本次体验中；完全关闭应用后清除。不安装可下载 ruler-client-experience，解压打开 client-acceptance.html 看中文结果和截图。

用户无需改配置、阅读代码或运行命令，只需回复“通过”或“不通过＋现象”。

## 风险、下一块与回退

当前可直接体验的是离线虚构文字，公网服务、账号交付与真机安装仍未验证。文字接收不是文件分类归档；下一块优先做持久文件暂存票据，再做手动分类、案件选择/指派及正式文件登记，继续保留全部原始需求。

可回退本轮客户端/模块注册；没有迁移，不删除已保存归集记录、原文件、数据卷或字段密钥。旧客户端没有新入口，不受新增接口影响；新客户端需配套本轮后端才能使用在线待定区。不得据此合并或生产部署。
