# RULER 客户端

Flutter 3.38.7 / Dart 3.10.7，已实现离线虚构演示及真实测试 API 的登录、案件、常规任务页面。
安装与边界见仓库根目录 README 和 docs/阶段11A2A验收报告.md。默认包没有服务地址，不能直接登录。
Riverpod 管理单一内存会话，go_router 与嵌套 Navigator 处理账号隔离；Dio 5.9.0 连接已实现的 REST API。系统文件选择、上传/下载和待定附件分类归档已接入；drift 离线缓存尚未接入。

开发者构建时通过 `--dart-define=RULER_API_URL=...` 注入受控 HTTPS 测试服务源地址（不含路径或凭据）；本机可 HTTP。不要把此配置任务交给项目所有者。
`tool/connected_e2e.dart` 由根目录 `scripts/test-client-api.mjs` 启动，使用隔离 Nest/PostgreSQL/Redis 验证真实网络与持久化，不依赖固定测试账号；不能单独拿它充当用户注册或服务部署脚本。

6A3B：待定附件可提取 PDF/DOCX 正文、查看规则建议和候选案号；仅预填分类，用户仍需选案件并确认。预览单次接收超时 40 秒（其他请求仍为 20 秒），401 刷新重试保留该时限。正文只在弹窗内存中显示，关闭/会话结束移除；手动复制属于用户操作，不自动复制或持久缓存。离线固定示例明确标注，不能当作真实解析。详见 [中文验收报告](../docs/阶段6A3B验收报告.md)。

6A3C：正文候选案号带入选案窗口，点击候选以完整案号查本人案件；未命中不隐式扩大，手动搜索清除精确条件。结果核对同一案号、分页、身份与摘要，错误不显示成未命中。整体滚动支持窄屏大字，必须选择案件及分类并最终确认归档。
