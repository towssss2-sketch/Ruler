# document 模块边界

负责：文件存储与配额（阶段 4）。

阶段 4A 提供 `storage/StorageService` 抽象端口、S3Driver（本机 MinIO）、OssDriver（原生 ali-oss）、配置工厂及 StorageModule。阶段 4B 已通过 DocumentModule 接入主应用；仅适配层导入供应商 SDK。

真实 MinIO 场景验证签名 PUT/GET、复制、元数据、删除、篡改与过期拒绝。OSS 只执行离线签名/适配器契约测试，未连接真实云。物理删除仅是底层能力，不等于文档软删除。

阶段 4B 实现预签名、登记、分类分页、版本、下载、可见性和软删除。全局 JWT、CaseAccessGuard 和事务内父案件锁共同保护；当前仅 OWNER，阶段 9 再开放协作角色。上传票据持久化操作者、来源、元数据及临时/正式对象键；签名 URL 不入库或日志。所有者行锁保护跨案件配额，票据完成与容量、审计同事务。

正式对象只通过服务端条件复制写入，旧上传签名只能写临时键。过期一分钟后的票据由每分钟批次回收，每批最多十条；先锁案件和票据，已登记正式对象（含软删除）永不自动物理删除。失败保留票据重试，不在数据库提交结果不确定时立即删对象。详见 docs/阶段4B文件业务约定.md。
