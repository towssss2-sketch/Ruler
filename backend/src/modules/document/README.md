# document 模块边界

负责：文件存储与配额（阶段 4）。

阶段 4A 已提供 `storage/StorageService` 抽象端口、S3Driver（本机 MinIO）、OssDriver（原生 ali-oss）、环境配置工厂及可注入 StorageModule。仅适配层导入供应商 SDK；通过独立测试模块验证注入，主应用暂不导入该模块，不开放未经资源授权的存储接口。

真实 MinIO 场景验证签名 PUT/GET、复制、元数据、删除、篡改与过期拒绝。OSS 只执行离线签名/适配器契约测试，未连接真实云。物理删除仅是底层能力，不等于文档软删除。

阶段 4B 再实现文档登记、版本、配额和全部资源接口。须使用全局 JWT、CaseAccessGuard、共享 Prisma 生命周期、事务审计和父案件锁；不能让客户端随意指定 storageKey。签名 URL 是凭据，至多十分钟且不能写日志或数据库。直传目标应隔离为待登记对象，核验后复制到正式不可被旧上传签名覆盖的对象键；跨数据库与对象存储失败要有重试/补偿方案。
